# Table of Contents

1. Brand Vision

MagicBook 致力於打造一套專為教育工作者設計的互動教材工具（Interactive Teaching Tool）。

MagicBook 不提供教材內容（Teaching Content）。

MagicBook 提供的是一套讓教材更容易建立、更容易管理、更容易教學、更容易學習的工具。

使用者只需準備自己的教材內容（Content）。

MagicBook 負責將教材轉化為更有效率、更具互動性的學習體驗。

MagicBook 的核心價值不是取代老師，而是協助老師更有效率地完成教學。


# 2. Core Philosophy
MagicBook 借給你廚具（Tool），讓你料理自己的食材（Content）。

MagicBook 提供的是工具（Tool）。

教材（Content）永遠屬於使用者。

MagicBook 不提供教材（Teaching Content）。

MagicBook 不販售教材（Teaching Content）。

MagicBook 的責任是讓使用者的教材發揮最大的教學價值，而不是提供教材內容。

MagicBook 的每一項產品設計，都必須符合本核心理念。

---

# 3. Business Model

MagicBook 採工具授權（Tool Licensing）模式。

MagicBook 提供的是工具（Tool），而不是教材（Teaching Content）。

使用者自行建立、整理及管理自己的教材。

MagicBook 不販售教材。

MagicBook 不提供教材。

教材的智慧財產權（Intellectual Property）永遠屬於教材建立者。

MagicBook 的價值，在於提供最好的教學工具，而不是教材內容。

使用者付費購買的是 MagicBook 的工具使用權（Tool License），而非教材所有權（Content Ownership）。

---

MagicBook 的商業模式可以用一句話說明：

> **MagicBook 借給你廚具（Tool），讓你料理自己的食材（Content）。**

教材（Content）由使用者自行準備。

MagicBook 提供的是完成教材所需的工具（Tool）。

當授權（License）結束時，

MagicBook 收回工具（Tool）。

使用者仍擁有自己的原始教材（Original Content）。

MagicBook 專屬工具（Tool）及服務（Service）則停止提供。
